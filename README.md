## 📌 Introduction

Reproduce the ACT (Action Chunking Transformer) baseline on the RoboSynChallenge benchmark: 11 dual-arm dexterous manipulation tasks in the EmbodiChain simulator.

- Paper: [ACT: Action Chunking with Transformers](https://arxiv.org/abs/2304.13705)
- Competition: [RoboSynChallenge 2026](https://robosyn-bench.net/)
